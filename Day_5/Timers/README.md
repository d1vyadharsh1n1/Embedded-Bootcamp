# 8051 Timers

The 8051 has two timers. They can be used as:

* Timers (generate time delay)
* Counters (count events happening outside MC)

---

# Basic Timer Registers

* **Timer 0** – 16 bits
* **Timer 1** – 16 bits

8051 has an **8-bit architecture**.

So, each timer is accessed by two separate registers.

* **Timer 0** – TH0 (Timer 0 high byte), TL0 (Timer 0 low byte)
* **Timer 1** – TH1 (Timer 1 high byte), TL1 (Timer 1 low byte)

---

# TMOD Register (Timer Mode Register)

Used to set timer operation modes.

8-bit register where,

* Upper 4 bits – Timer 1
* Lower 4 bits – Timer 0


+------+------+------+------+------+------+------+------+
| Gate | C/T  | M1   | M0   | Gate | C/T  | M1   | M0   |
+------+------+------+------+------+------+------+------+
|            Timer 1         |            Timer 0       |
+----------------------------+--------------------------+


## Gate

Start and stop of timer (software) is controlled by **TR (Timer Run)** bits.

* TR0
* TR1

```text
Start Timer 0 : SETB TR0        Stop Timer 0 : CLR TR0

Start Timer 1 : SETB TR1        Stop Timer 1 : CLR TR1
```

### If Gate = 0

Software control.

Only `SETB TRx` and `CLR TRx` are needed.

### If Gate = 1

Hardware control.

Software + external source (interrupt pins) required.

* Pin P3.2 for Timer 0
* Pin P3.3 for Timer 1

> Even if TRx is turned on by `SETB TRx`, we can start/stop timers externally using a switch.

## C/T (Clock/Timer)

Determines whether the register is being used as a clock or timer.

* **C/T = 0** – Timer
* **C/T = 1** – Counter

## Timer Modes

| M1 | M0 | Mode | Operating Mode   |
| -- | -- | ---- | ---------------- |
| 0  | 0  | 0    | 13-bit timer     |
| 0  | 1  | 1    | 16-bit timer     |
| 1  | 0  | 2    | 8-bit timer      |
| 1  | 1  | 3    | Split timer mode |

Modes:

* Mode 0 – 13-bit timer mode
* Mode 1 – 16-bit timer mode
* Mode 2 – 8-bit timer mode

**Example:**

```text
TMOD = 00010000 = 10H → Timer 1, Mode 1
```

---

# Mode 1 – 16-bit Timer

Allows values from:

```text
0000H to FFFFH
```

After TH and TL values are loaded:

* Start timer using `SETB TRx`
* Counts from the entered value until `FFFFH`
* Rolls over to `0000H`
* `TF` (Timer Flag) is set HIGH
* Stop timer using `CLR TRx`

---

# Mode 0 – 13-bit Timer

The timer ignores bits **D7 to D5**, making it an **8 + 5 = 13-bit timer**.

+-----+-----+-----+-----+-----+-----+-----+-----+---------+-----+-----+-----+-----+-----+
| D15 | D14 | D13 | D12 | D11 | D10 | D9  | D8  | Ignored | D4  | D3  | D2  | D1  | D0  |
+-----+-----+-----+-----+-----+-----+-----+-----+---------+-----+-----+-----+-----+-----+
|                    THx                        |                TLx                    |
+-----------------------------------------------+---------------------------------------+

---

# Mode 2 – 8-bit Timer

Allows values from:

```text
00H to FFH
```

Auto Reload Mode.

* TH is loaded with the original 8-bit value.
* TL receives a copy.
* TL increments until `FFH`.
* Rolls over to `00H`.
* Sets `TF` HIGH.
* Reloads automatically with the original value stored in TH.

Since it reloads automatically, it is often used to generate baud rates.

> Reloaded by hardware → Less overhead.

---

# Source

* **Timer** → Crystal frequency
* **Counter** → Pulse from outside 8051

## C/T = 1 (Counter)

Counter counts up as pulses are fed from Pins **14** and **15** (Timer input pins).

| Pin | Port Pin | Function | Description                    |
| --- | -------- | -------- | ------------------------------ |
| 14  | P3.4     | T0       | Timer/Counter 0 external input |
| 15  | P3.5     | T1       | Timer/Counter 1 external input |

Timer is triggered during a **falling edge**.

* Falling edge on **P3.4** → T0 increments.
* Falling edge on **P3.5** → T1 increments.

(Usually a hardware trigger – practical.)

---

# TCON Register

**Timer Control Register**

* 8-bit register
* Used for TR0 and TR1 flags
* Bit-addressable register

## For Timer 0

```text
SETB TR0 = SETB TCON.4
CLR TR0  = CLR TCON.4

SETB TF0 = SETB TCON.5
CLR TF0  = CLR TCON.5
```

## For Timer 1

```text
SETB TR1 = SETB TCON.6
CLR TR1  = CLR TCON.6

SETB TF1 = SETB TCON.7
CLR TF1  = CLR TCON.7
```

# Time Delay Calculation

**Note:** 8051 timers use **1/12 of XTAL frequency**, regardless of machine cycle time.

So,

If XTAL frequency = **11.5092 MHz**

```text
Timer Clock Frequency = 11.5092 MHz / 12 = 921.6 kHz
```

Each clock period:

```text
T = 1 / 921.6 kHz = 1.085 μs
```

Time delay:

```text
Time Delay = Number of Counts × 1.085 μs
```

### Example

```text
TL0 = F2H
TH0 = FFH
```

The number of counts for the rollover is:

```text
FFFFH − FFF2H = 0DH (13 decimal)
```

However, we add **one** to 13 because of the extra clock needed when it rolls over from `FFFFH` to `0000H` and raises the TF flag.

This gives:

```text
14 × 1.085 μs = 15.19 μs
```

for half the pulse.

For the entire period:

```text
T = 2 × 15.19 μs = 30.38 μs
```

This is the time delay generated by the timer.
